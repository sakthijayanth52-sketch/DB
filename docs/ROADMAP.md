# DB Roadmap

1. Foundation: Android shell, backend API, secure configuration, model adapter.
2. Personal AI: accounts, conversation history, long-term memory, knowledge/RAG.
3. Agent: tools, multi-step tasks, coding, scheduled tasks.
4. Ownership: provider-independent inference and evaluation of self-hosted/open-weight models.
5. Public product: production deployment, monitoring, backups, privacy/terms, Play Store release.
