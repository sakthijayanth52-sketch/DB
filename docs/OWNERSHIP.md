# DB Project Ownership & Provenance

## Project identity

- Project: DB
- Project initiator and intended owner: the project owner
- Purpose: a personal AI assistant designed to be controlled, developed, and operated by its owner.

## Authorship statement

DB is a personal AI project initiated and directed by its owner. This document records the project's intended authorship and ownership provenance; it is not a legal opinion and does not by itself determine intellectual-property rights under any jurisdiction.

## Ownership boundary

The owner intends to control the DB-specific application code, architecture, prompts/personality, memory system, stored data, knowledge assets, deployment configuration, and product branding, subject to applicable law and any third-party licenses or agreements.

Third-party models, SDKs, libraries, operating-system components, and other dependencies remain subject to their respective licenses and terms. Using a third-party model through an API does not transfer ownership of that model to DB's owner.

## Independence goal

DB's model layer is intentionally separated from the Android client and backend so that the model provider can be replaced. A future self-hosted or appropriately licensed open-weight model can be integrated without redesigning the DB product.

## Provenance

The Git repository history is part of the project's development record. Material DB-specific changes should be committed to this repository so the project has a persistent development history.
